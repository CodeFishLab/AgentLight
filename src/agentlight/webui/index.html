Agent 集成

Codex检测中支持桌面版和 CLI
Claude Code检测中权限、等待输入、失败与完成事件

「一键安装 / 修复」会改写 Codex 与 Claude Code 的配置，改动前自动备份到备份目录。两边各自还要做一步，见下。

Codex

  1. 点上面的「一键安装 / 修复」。
  2. 打开 PowerShell，运行 codex。
  3. 输入 /hooks。
  4. 如果出现 Hooks need review，选择 Trust all and continue。
  5. 审核时确认所有命令都指向这个脚本：
    —
    这里是 .ps1 而不是 agentlightctl.exe：Codex 走 PowerShell 脚本，Claude Code 才走 exe。两边路径本来就不一样，不是装错了。
  6. 完全退出 Codex，包括右下角系统托盘里的那个，然后重新打开 —— hooks.json 只在启动时读一次，光关窗口不算。
  7. 新建一个任务再测试，别在旧任务里发消息 —— 旧任务用的是重启前的旧配置。发一条测试状态灯，灯应该跟着变，本页的「活动会话」也会出现真实事件。

Claude Code

  1. 点上面的「一键安装 / 修复」。
  2. 重启 Claude Code。不需要信任步骤 —— 它读 ~/.claude/settings.json，不做命令审核。
  3. 安装时会顺带写入可选状态栏（—），在 Claude Code 里显示灯的状态和剩余额度。
  4. 额度由 AgentLight 读取 Claude 登录凭据后台获取，Claude Code 不必一直开着。凭据过期时在终端运行 claude 重新登录即可，AgentLight 会自动恢复，不用重启它。

卸载 AgentLight

移除程序、Agent 集成和自启动项，默认保留用户设置与备份。

卸载 AgentLight？

Windows 卸载程序即将打开。确认卸载后，灯光联动和当前 Web 页面会停止。

  • 程序文件、AgentLight 创建的 Hooks、Claude statusLine 和自启动项会被移除。
  • 用户设置、日志与备份会保留，方便以后重新安装。
  • 其他 Claude 或 Codex 配置不会被修改。
